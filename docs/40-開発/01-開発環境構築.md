**バージョン**: 1.0.0  
**作成日**: 2025年12月6日  
**最終更新日**: 2025年12月6日

---

## 前提条件

- Docker Desktop がインストールされ、起動していること
- Git がインストールされていること（推奨）

---

## セットアップ手順

### 1. プロジェクトのクローン（既に作成済みの場合はスキップ）

```bash
# プロジェクトディレクトリに移動
cd D:\Code

# プロジェクトが既に存在する場合は、このステップは不要
```

### 2. Dockerコンテナの起動

```powershell
# monetimディレクトリに移動
cd monetim

# Dockerコンテナを起動
docker compose up -d
```

### 3. アプリケーションキーの生成

```powershell
docker compose exec laravel.test php artisan key:generate
```

### 4. データベースマイグレーション

```powershell
docker compose exec laravel.test php artisan migrate
```

### 5. ストレージ権限の設定

```powershell
docker compose exec laravel.test chmod -R 777 storage bootstrap/cache
docker compose exec laravel.test chown -R sail:sail storage bootstrap/cache
```

### 6. 動作確認

ブラウザで `http://localhost` にアクセスして、Laravelのウェルカムページが表示されることを確認してください。

## 開発コマンド

### Artisanコマンド

```powershell
# マイグレーション実行
docker compose exec laravel.test php artisan migrate

# モデル作成
docker compose exec laravel.test php artisan make:model ModelName

# コントローラー作成
docker compose exec laravel.test php artisan make:controller ControllerName

# マイグレーション作成
docker compose exec laravel.test php artisan make:migration create_table_name
```

### Composerコマンド

```powershell
# パッケージインストール
docker compose exec laravel.test composer install

# パッケージ追加
docker compose exec laravel.test composer require package-name
```

### npmコマンド

```powershell
# パッケージインストール
docker compose exec laravel.test npm install

# 開発サーバー起動
docker compose exec laravel.test npm run dev

# ビルド
docker compose exec laravel.test npm run build
```

### データベース接続

```powershell
# PostgreSQLに接続
docker compose exec pgsql psql -U sail -d monetim
```

## 便利なエイリアス設定

PowerShellで以下のエイリアスを設定すると便利です：

```powershell
# 現在のセッションのみ有効
Set-Alias sail "docker compose exec laravel.test"

# 使用例
sail php artisan migrate
sail composer install
sail npm install
```

## トラブルシューティング

### コンテナが起動しない

```powershell
# コンテナの状態を確認
docker compose ps

# ログを確認
docker compose logs laravel.test

# コンテナを再起動
docker compose restart laravel.test
```

### 権限エラー

```powershell
# ストレージ権限を再設定
docker compose exec laravel.test chmod -R 777 storage bootstrap/cache
docker compose exec laravel.test chown -R sail:sail storage bootstrap/cache
```

### データベース接続エラー

`.env`ファイルのデータベース設定を確認：

```env
DB_CONNECTION=pgsql
DB_HOST=pgsql
DB_PORT=5432
DB_DATABASE=monetim
DB_USERNAME=sail
DB_PASSWORD=password
```
