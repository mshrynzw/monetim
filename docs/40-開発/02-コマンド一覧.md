## Docker Composeコマンド

### コンテナ管理

```powershell
# コンテナ起動
docker compose up -d

# コンテナ停止
docker compose down

# コンテナ再起動
docker compose restart

# コンテナ状態確認
docker compose ps

# ログ確認
docker compose logs laravel.test
docker compose logs -f laravel.test  # リアルタイム表示
```

### コンテナ内でのコマンド実行

```powershell
# 基本形式
docker compose exec laravel.test [コマンド]

# 例
docker compose exec laravel.test php artisan migrate
docker compose exec laravel.test composer install
docker compose exec laravel.test npm install
```

## Laravel Artisanコマンド

### マイグレーション

```powershell
# マイグレーション実行
docker compose exec laravel.test php artisan migrate

# マイグレーションロールバック
docker compose exec laravel.test php artisan migrate:rollback

# マイグレーションリセット
docker compose exec laravel.test php artisan migrate:reset

# マイグレーション再実行
docker compose exec laravel.test php artisan migrate:refresh

# マイグレーション作成
docker compose exec laravel.test php artisan make:migration create_table_name
```

### モデル・コントローラー作成

```powershell
# モデル作成
docker compose exec laravel.test php artisan make:model ModelName

# コントローラー作成
docker compose exec laravel.test php artisan make:controller ControllerName

# リソースコントローラー作成
docker compose exec laravel.test php artisan make:controller ControllerName --resource

# モデル + マイグレーション + コントローラー + ファクトリー + シーダー
docker compose exec laravel.test php artisan make:model ModelName -a
```

### キャッシュ管理

```powershell
# キャッシュクリア
docker compose exec laravel.test php artisan cache:clear

# 設定キャッシュクリア
docker compose exec laravel.test php artisan config:clear

# ビューキャッシュクリア
docker compose exec laravel.test php artisan view:clear

# ルートキャッシュクリア
docker compose exec laravel.test php artisan route:clear

# 全キャッシュクリア
docker compose exec laravel.test php artisan optimize:clear
```

### その他

```powershell
# アプリケーションキー生成
docker compose exec laravel.test php artisan key:generate

# ルート一覧表示
docker compose exec laravel.test php artisan route:list

# Tinker起動
docker compose exec laravel.test php artisan tinker
```

## データベースコマンド

### PostgreSQL接続

```powershell
# PostgreSQLに接続
docker compose exec pgsql psql -U sail -d monetim

# SQL実行
docker compose exec pgsql psql -U sail -d monetim -c "SELECT * FROM users;"
```

### データベースバックアップ

```powershell
# バックアップ作成
docker compose exec pgsql pg_dump -U sail monetim > backup.sql

# バックアップ復元
docker compose exec -T pgsql psql -U sail monetim < backup.sql
```
