## 1. テーブル一覧

### 1.1 認証・ユーザー関連

#### m_users
ユーザー情報を管理するテーブル

| カラム名 | データ型 | 制約 | 説明 |
|---------|---------|------|------|
| id | uuid | PK | ユーザーID |
| tenant_id | uuid | FK, NOT NULL | テナントID（所属テナント） |
| name | string(255) | NOT NULL | ユーザー名 |
| email | string(255) | UNIQUE, NOT NULL | メールアドレス |
| email_verified_at | timestamp | NULL | メール認証日時 |
| password | string(255) | NOT NULL | パスワード（ハッシュ） |
| role | string(50) | NOT NULL | ロール（system-admin, tenant-admin, employee） |
| remember_token | string(100) | NULL | リメンバートークン |
| created_at | timestamp | NOT NULL | 作成日時 |
| created_by | uuid | FK, NULL | 作成者ID |
| updated_at | timestamp | NOT NULL | 更新日時 |
| updated_by | uuid | FK, NULL | 更新者ID |
| deleted_at | timestamp | NULL | 削除日時（ソフトデリート） |
| deleted_by | uuid | FK, NULL | 削除者ID |

**インデックス**:
- `tenant_id`
- `email`
- `role`
- `created_by`
- `updated_by`
- `deleted_at`

**RLSポリシー**:
- テナント分離（system-adminは全テナントアクセス可能）
