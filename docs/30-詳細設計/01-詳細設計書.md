# monetim 詳細設計書

## 1. 認証・認可機能

### 1.1 ログイン機能

**処理フロー**:
1. ユーザーがログインフォームに入力
2. 認証処理（Laravel Breeze）
3. セッションにユーザー情報とテナント情報を保存
4. ダッシュボードにリダイレクト

**実装**:
- `app/Http/Controllers/Auth/AuthenticatedSessionController.php`
- `resources/js/Pages/Auth/Login.tsx`

### 1.2 ロール管理

**実装**:
- `app/Models/User.php`: `role`カラムでロールを管理
- `app/Policies/UserPolicy.php`: 権限チェック
- ミドルウェア: `app/Http/Middleware/EnsureUserHasRole.php`

---

## 2. テナント管理機能

### 2.1 テナント作成

**処理フロー**:
1. システム管理者がテナント情報を入力
2. テナントレコードを作成
3. デフォルト設定を作成
4. 初期データを投入

**実装**:
- `app/Http/Controllers/Admin/TenantController.php`
- `app/Models/Tenant.php`
- `app/Services/TenantService.php`

### 2.2 テナント設定

**設定項目**:
- 打刻の種類
- 勤務時間計算ルール
- 休暇の種類
- 給与計算ルール
- 承認フロー

**実装**:
- `app/Http/Controllers/Tenant/SettingsController.php`
- `app/Models/TenantSetting.php`

---

## 3. 出退勤機能

### 3.1 打刻機能

**処理フロー**:
1. 従業員が打刻ボタンをクリック
2. 打刻タイプを判定（出勤/退勤/休憩など）
3. GPS位置情報を取得（設定で有効な場合）
4. 打刻レコードを作成
5. シフトを自動判定・作成

**実装**:
- `app/Http/Controllers/Attendance/PunchController.php`
- `app/Models/AttendanceRecord.php`
- `app/Models/Shift.php`
- `app/Services/AttendanceService.php`

### 3.2 打刻種類設定

**実装**:
- `app/Models/PunchType.php`
- `app/Http/Controllers/Tenant/PunchTypeController.php`

---

## 4. 勤務時間計算機能

### 4.1 勤務時間計算ロジック

**処理フロー**:
1. 打刻データを取得
2. シフトごとに勤務時間を計算
3. 休憩時間を計算
4. 実労働時間を計算
5. 残業時間を計算
6. 深夜労働時間を計算

**実装**:
- `app/Services/WorkTimeCalculationService.php`
- `app/Models/WorkTimeRecord.php`

### 4.2 計算ルール設定

**実装**:
- `app/Models/WorkTimeRule.php`
- `app/Http/Controllers/Tenant/WorkTimeRuleController.php`

## 5. 休暇管理機能

### 5.1 休暇申請

**処理フロー**:
1. 従業員が休暇申請フォームに入力
2. 申請レコードを作成
3. 承認者に通知
4. 承認待ち状態にする

**実装**:
- `app/Http/Controllers/Leave/LeaveRequestController.php`
- `app/Models/LeaveRequest.php`
- `app/Services/LeaveService.php`

### 5.2 承認フロー

**処理フロー**:
1. 承認者が申請を確認
2. 承認/却下を選択
3. 次の承認者に回付（複数段階の場合）
4. 最終承認で申請を確定
5. 申請者に通知

**実装**:
- `app/Http/Controllers/Leave/LeaveApprovalController.php`
- `app/Models/LeaveApproval.php`

---

## 6. 給与計算機能

### 6.1 給与計算ロジック

**処理フロー**:
1. 計算期間の勤務時間データを取得
2. 基本給を計算
3. 残業手当を計算
4. 深夜労働手当を計算
5. 各種手当を計算

- `app/Services/PayrollCalculationService.php`

### 6.2 給与明細生成

**実装**:
- `app/Services/PayrollSlipService.php`
- `app/Models/PayrollSlip.php`
