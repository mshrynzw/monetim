# 結合テスト

**バージョン**: 1.0.0  
**作成日**: 2025年12月6日

---

## 概要

結合テストは、複数のコンポーネントが連携して正しく動作することを確認するテストです。

---

## テスト実行方法

```powershell
# 結合テスト実行
docker compose exec laravel.test php artisan test --testsuite=Integration
```
